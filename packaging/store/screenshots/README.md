# Store screenshots

PNG files uploaded to the Partner Center listing, numbered in display order
(`ps_1.png`, `ps_2.png`, ...). Partner Center requires at least 1366x768
(1920x1080 recommended) and accepts up to 10 desktop screenshots.

* `ps_1.png`: `tail -F` following a training log whose tqdm progress bars,
  redrawn with a bare carriage return, appear one update per line.

Capture them with the Store package installed (the `tail` alias), in Windows
Terminal, on a live log so `tail -f` output is visible.
